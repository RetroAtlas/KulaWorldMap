# 29. Several drafts in one pack

## What and why

A draft goes onto the disc one at a time: its `into` names one slot, the dialog fits that level to that slot, in place, with the pack rebuilt or with the pack moved into the free sectors, and the patch carries that one placement ([docs/disc.md](../docs/disc.md)). A second draft is a second patch, made against the image the first one wrote, so two levels in one world are two patches applied in order, while the tool takes several, `--level X --into PACK#slot` repeated in pairs, each placed over the image as the earlier ones left it ([docs/disc.md](../docs/disc.md)). Several drafts into one pack, a world of one's own as one patch, was put aside for after the editor shipped.

## Sketch

The placement already reckons with the pack's other levels, since a rebuild recompresses them at level 9 to make room and the patch carries them, which was decided and allowed, so several streams into several slots of one pack is the same arithmetic over a list: in place where each fits its own slot's bytes, else one rebuild of the pack with all of them laid in slot order, else one move into the free sectors, with the fit shown for the set rather than the one. The drafts that go together are the ones whose `into` names the same pack, which the dialog could gather from the list and show as the pack's twenty slots with a draft or the shipped level in each; the pack's name table takes each title's ASCII where the pack is rebuilt. The PPF and the xdelta are then one patch from the original image to the final one, the sectors of every placement merged, which is what the patch writer does for one placement's sectors and would do for the list's. The Python tool takes the list already, as does the browser's placer beneath the dialog, and the fixture's two sets hold the two sides to the same bytes, since a path the tool cannot take is a path no test can hold.

Open: what the dialog says of the game's own levels the set displaces, which the player loses for as long as the patch is applied; whether a set across packs, a level in a world and its final in the finals pack, is one patch too; and how the dialog's one `into` per draft grows into a set without a second place for the same choice. Settled by the slot: the number the pause screen shows is the slot's and not the level's, so a pack with every slot replaced still numbers its levels as the world does. Ruled out: a pack exported on its own without the image, since a standalone pack of the game's levels is the game's data.
