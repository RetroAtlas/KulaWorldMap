# Backlog

The open questions, one file per question, numbered once and never renumbered: a number is not reused after its file goes, so the sequence has gaps. [README.md](../README.md) is the summary a reader meets first, [CLAUDE.md](../CLAUDE.md) carries the conventions a fresh session reads first, and [docs/](../docs/) carries the formats and the addresses they came from.

A question earns a file when the gap between finding it and answering it is long enough for the reasoning to be forgotten: what it would settle, a sketch of how, and what has already been ruled out. A nit fixed within the hour is a commit message, not an entry here. The commit that answers a question deletes its file and says what was decided, so the history of the folder is in git and the folder itself is only what is still open. A measurement here carries the date it was taken and points at the command that reproduces it, or says plainly that it is stale.

Anything that needs the disc says so, because the disc is never committed and most of what is left to learn is on it.
